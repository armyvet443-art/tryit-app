# Try It App 🚀

A simple interactive app built with **HTML, CSS, and JavaScript**.  
Deployed with **Azure Static Web Apps**.

## ✨ Features
- 👋 Greeting with name input
- 🖱 Click counter (persists with localStorage)
- 🎨 Background color changer
- 🌙 Dark mode toggle (persists)
- ⭐ Add entries with categories (saved in localStorage)
- 📋 Entries list displayed below

## 📦 Tech Stack
- HTML
- CSS
- JavaScript
- Azure Static Web Apps
